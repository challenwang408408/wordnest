# 小学单词

`primary-school.json` 是可导入词芽的 1,587 条完整词库。`primary-school-sources.json` 保存原词头、原释义和公开来源链接，便于逐条追溯。原文件 SHA-256 为 `82bd58cfecca1e64ad6ae132c687727deba03de1a214e1c80d2db2dc27b4b225`。

来源是工作区此前整理的 `w-王存正学习作业/x-小学英语单词库/词库.json`，包含 New Magic 1A–5B 的可获取词汇栏，以及牛津深圳版、人教 PEP、人教新起点等公开复习资料。它是供孩子复习使用的合并词库，不代表学校已确认的完整教学清单，也不是全国统一必会词表。

## 内容口径

- 1,099 个单词和 488 个短语/表达，合计 1,587 条，沿用原词头及 `strip().lower()` 去重口径。
- 复数、过去式、英美拼写变体、缩写和带省略号的句型保持独立词条，不再词干化。句型的例句填入自然内容；词头中的省略号表示可替换位置，音标只标示固定部分，省略号不发音。
- 新增词按小学常用语境选择一个核心释义，补充词性、美式 IPA、以 `·` 分隔的拼写音节和双语例句。由本次 Codex 会话编写，未调用付费补全 API。音节分隔用于辅助拼读，不能替代听音。
- 48 个与导入前日常阅读重合的词复用既有资料；例如 `may` 与 `May` 按现有不区分大小写的去重规则属于同一单词。导入不覆盖它们原来的释义、拼写展示或学习记录。
- 新词的美式释义中，`first floor` 指一楼，`second floor` 指二楼；`temperature` 本身表示温度/体温，不能直接等同于“发烧”。

## 导入与学习记录

导入脚本位于 `scripts/import_vocabulary.py`。默认只预检；显式 `--apply` 才在一个事务内写入。只接受已有的 SQLite 文件和明确的 `--profile-id`，任何数量、重复词或缺字段错误都会拒绝。

新词各建一份 `words` 与 `word_progress`，重合词只增加 `library_words` 关联。挑战继续使用原来的 `review_events` 与评分规则，同一个词在两库的答错不会拆成两份记录。应用启动不自动导入该文件。

这次导入只针对哥哥。妹妹词库保持原状。
