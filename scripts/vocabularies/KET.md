# KET词库

`ket.json` 保留2026-10-05合并导入时的“KET词库”来源归档，共 **1,986 条**。2026-10-18起，使用范围分为“KET-词组”204条与“KET-单词”1,782条。`ket-sources.json` 保存逐条来源、PDF页码、原文词头及订正映射。

## 来源与范围

1. [剑桥 A2 Key / A2 Key for Schools 官方词表](https://www.cambridgeenglish.org/Images/506886-a2-key-2020-vocabulary-list.pdf)，正文标注 **August 2025**，共32页。URL虽然含2020，版本以PDF正文为准。提取字母表第4–23页与附录第24–32页明确列出的词头，处理明确的拼写变体后为1,807条。它是备考参考，官方明确说明并非考试所有词汇的穷尽表。
2. 家长提供《204个KET（青少版）常考固定搭配清单》，共9页、204个编号。原始网盘分享链接见来源清单，不保存临时签名下载地址。该资料来自培训方，不能视为剑桥官方范围声明。

两源重合25条，因此1,807 + 204 − 25 = 1,986。原有词库中951条可复用，只新建1,035个词。导入后哥哥三个词库的去重总量为2,807，不能把各库数量直接相加。

## 词条与订正规则

- 去重沿用词芽 `strip().lower()`。保留来源明确的英美拼写变体、缩写及短语；原表的释义标签不算词头。排版弯引号统一为ASCII引号。主题附录与字母正文重合的词不重复入库。
- 附录数字只收明确写出的词头，不把“等”自行展开成上千条数字组合。
- 新词由当前Codex会话编写一个核心中文义、相应词性、美式IPA、用`·`分隔的拼写音节，以及简短中英例句。新编的剑桥词表例句不照抄官方例句。未调用付费补全API。
- 两份来源重合的新词优先采用固定搭配资料所选的核心义；例如`take off`采用“起飞”义。当前产品每词只展示一个核心释义，合并来源不等于覆盖所有义项。
- 同拼写旧词完整复用已有资料，不覆盖家长编辑、掌握状态或学习历史。因此旧词的释义与本次来源选择的词义可能不同，符合项目原有一词一记录规则。旧库`as well`、`make sure`含音节分隔符周围空格，`awesome`旧音节字段为`aw·some`，本次也原样保留并在来源审计明示；严格音节复原检查适用于全部新词，其余旧词同样通过。
- 固定搭配第134项原文写`make up`，但释义“弥补”和例句对应`make up for`，据此订正；第159/160项的`sent for`/`sent out`改为词表基形`send for`/`send out`；第77/123/158项只统一省略号两侧空格。
- 第156项保留正确搭配`provide for`，按“供养”义改写不匹配的释义和例句。原表两条`make up`因第134项订正而得到两个不同且正确的词头，204个编号全部有去向。
- 带`...`的词头表示可替换位置；例句填入自然内容，音标不朗读省略号。拼写音节用于辅助认读，不代替听标准发音。

## 恢复原词组类别

拆分依据是 `ket-sources.json` 的 `entries[].sources[].document == "ket-204-phrases"`。204个编号均有唯一去向，与剑桥来源重合的25条也只归词组库。其余1,782条归单词库；两库无交集，完整覆盖原1,986条。

这是恢复原资料类别，不是按空格或语言学规则重分词头。原资料第4项 `arrive` 仍在词组库；剑桥原表的 `ice cream`、`bus stop` 等其他多词表达仍在单词库。

对现有数据库先预检，再显式应用：

```bash
.venv/bin/python scripts/split_ket_library.py \
  --database /path/to/existing/wordnest.db \
  --profile-id 1 --profile-slug brother --library-id 4
# 核对并备份后，同一命令追加 --apply。
```

迁移保留原库ID并改名“KET-单词”，新建“KET-词组”，在一个事务内迁移204个关联。词条及资料、学习历史、其他库关联均原样保留。默认只读；数据库不存在、档案不符、来源集合漂移或目标名称冲突均拒绝。重复执行只在两库精确匹配终态时返回零变化。无需重启应用。

已拆分的数据库不要再次运行下方旧合并导入命令，否则会新建旧名“KET词库”。原文件保留用于追溯，不代表当前线上分类。

## 历史导入与学习记录

管理员在已有数据库副本上先预检，确认来源及目标孩子后才显式写入：

```bash
.venv/bin/python scripts/import_vocabulary.py scripts/vocabularies/ket.json \
  --profile-id 1 --database-path /path/to/existing/wordnest.db
# 显式写入时追加 --apply；不要把示例数据库路径直接用于生产。
```

脚本默认只读，不自动创建数据库或孩子，不读取`.env`，不调用AI。完整条数与JSON中的`expected_count`必须一致，全部字段和唯一拼写通过检查后才在一个事务内导入。重复执行不产生重复关联或重置进度。

同一个词跨日常阅读、小学单词、KET词库共用`word_id`、学习状态及累计错次。妹妹词库独立；应用启动不会自动导入数据。生产导入前另行备份并冻结校验，部署说明见项目发布记录。
